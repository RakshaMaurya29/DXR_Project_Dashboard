# 📊 DXR Project Tracking Dashboard

## Project Overview

The **DXR Project Tracking Dashboard** is an interactive Power BI dashboard developed to monitor project execution, test cycle progress, test coverage, and delivery status in real time. It provides project managers and stakeholders with a centralized view of testing activities, helping them track project health, monitor completion status, and identify pending deliverables.

---

## Business Problem

Managing project testing activities manually across multiple Excel files made it difficult to:

- Monitor project progress
- Track completed and remaining test cases
- Measure test coverage
- Analyze failure percentage
- Monitor project deliverables
- Generate real-time management reports

This dashboard provides a centralized reporting solution for project monitoring and decision-making.
